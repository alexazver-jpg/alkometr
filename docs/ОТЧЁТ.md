Работа 10.11.2026 прерывалась перезагрузкой компьютера (синий экран). Все числа ниже получены

## 1. Репозиторий GitHub

Приватный репозиторий **не создан**. Причина: в системе нет `gh` (GitHub CLI) и не задан
`GITHUB_TOKEN`, поэтому публикация из этой сессии невозможна. Исходники лежат в локальном
репозитории `alkometr` и в локальном архиве `E:\ProectsAutoClaw\АлкоМетр`.

Команды для владельца — из папки `alkometr`:

```bash
gh auth login
gh repo create alkometr --private --source=. --remote=origin --push
gh repo view --json name,url,isPrivate
```

Ожидаемый результат: третья команда печатает `"isPrivate": true` и URL репозитория; `origin`
указывает на него. До этого шага раздел «Репозиторий» в приёмке считается незакрытым.

## 6. Ручная проверка на эмуляторе

Проверялось после перезагрузки на эмуляторе Pixel_8, установлен debug-APK.

1. **Онбординг** — показывается при первом запуске, шаги вес → пол → порог → дисклеймер проходятся,
   «Пропустить» работает; после завершения повторно не появляется.
2. **Пустой экран** — «Трезв», нулевой уровень, статус «За руль можно сейчас», подсказка
   «Нажмите на сосуд, когда выпьете порцию».
3. **Добавление порции** — тап по сосуду добавляет порцию: значение и маркер шкалы растут, появляется
   строка последней порции с «Отменить», на шкале времени возникает маркер.
4. **Рост уровня** — при добавлении порций значение растёт, обновляются маркер шкалы и кривая на шкале
   времени. Смена степени сопровождается сменой цвета зоны и иконки-персонажа (кроссфейд 250 мс —
   по коду `BacGauge.kt`).
5. **Настройки** — экран открывается с главного, на месте профиль, пресеты, порог, единицы,
   резервная копия и сброс.

Инструментальные тесты (`androidTest`) не писались: перечисленное выше — ручная проверка, а не
автотесты.

## 7. Отклонения от ТЗ

| Пункт ТЗ | Факт | Причина |
|---|---|---|
| compileSdk 36 | compileSdk **37**, targetSdk 36 | Compose BOM 2026.09.00 (Compose 1.12.1) требует compileSdk 37; `android-37.0` — стабильный релиз, ТЗ разрешает максимальный стабильный compileSdk |
| Compose только через `buildFeatures.compose` | дополнительно плагин `org.jetbrains.kotlin.plugin.compose` 2.2.10 | без него AGP 9.5.1 не собирает Compose: «Starting in Kotlin 2.0, the Compose Compiler Gradle plugin is required» |
| kotlinx-serialization без версии | 1.9.0 | 1.12.0 собрана Kotlin 2.4 и несовместима со встроенным компилятором 2.2.10 (ошибка metadata 2.4.0) |
| Навигация через библиотеку | ручное состояние экранов + `BackHandler` | экранов три, `androidx.navigation` даёт лишнюю зависимость |
| Подписи «ч»/«мин» в `strings.xml` | в `Formatters` | эти строки проверяет JVM-тест без контекста Android |

Отклонения не меняют поведение приложения и не затрагивают расчётную модель.

## 8. Что осталось за рамками

* **Публикация на GitHub** — нет `gh` и `GITHUB_TOKEN`; команды в разделе 1.
* **Release-сборка** — собран и проверен только debug-APK; release требует собственного ключа
  подписи и `signingConfig`, которых в проекте нет.
* **Инструментальные тесты** — `androidTest` не писались, экраны проверены вручную (раздел 6).
* **CI** — автоматическая сборка на сервере не настраивалась.

## 9. Вывод

Приложение «АлкоМетр» 0.1.0 собирается, проходит 23 юнит-теста без падений, не имеет ошибок lint и
не запрашивает сетевых разрешений. Debug-APK готов к установке и проверен на эмуляторе.

Для передачи как продукта остаётся два шага владельца: создать приватный репозиторий командами
раздела 1 и собрать release с собственным ключом подписи.
