# АЛГОРИТМ РАСЧЁТА

Приложение моделирует концентрацию этанола в крови (BAC, blood alcohol concentration).
Внутри все значения — в **г/л**; численно 1 г/л = 1 ‰, поэтому на экране по умолчанию промилле.

## 1. Величины и константы

| Величина | Обозначение | Значение | Источник / смысл |
|---|---|---|---|
| Плотность этанола | ρ | 0,789 г/мл | физическая константа |
| Масса чистого спирта в порции | D | V × (ABV/100) × ρ | V — объём, мл; ABV — крепость, % об. |
| Коэффициент распределения | r | 0,71 (М) / 0,58 (Ж) / 0,65 (не указан) | формула Видмарка |
| Объём распределения | Vd | r × вес, л | 80 кг, муж → 56,8 л |
| Скорость всасывания | ka | 2,0 / 1,5 / 0,8 ч⁻¹ | натощак / обычно / плотно поел, кинетика 1-го порядка |
| Максимальная скорость выведения | Vmax | 0,15 г/л/ч (0,12…0,18) | средние данные фармакокинетики этанола |
| Константа Михаэлиса | Km | 0,02 г/л | «хвост» выведения, кривая не уходит в минус |
| Шаг интегрирования | Δt | 1 мин | детерминированно и достаточно точно |
| Горизонт прогноза | — | 24 ч от первой порции | дальше концентрация практически нулевая |

Константы не подгонялись под тесты: это физиологически обоснованные средние. Разброс
индивидуальных значений — до ±30 %, поэтому приложение называется расчётным, а не измерительным.

## 2. Уравнения

Для каждой порции i:

```
D_i  = V_i × (ABV_i / 100) × 0,789           [г этанола]
a_i(t) — масса ещё не всосавшегося алкоголя, г
da_i/dt = −ka × a_i ,   a_i(t_i) = D_i       [всасывание, 1-й порядок]
```

Суммарное поступление в кровь:

```
input(t) = ka × Σ a_i(t)                     [г/ч]
```

Баланс концентрации (выведение по Михаэлису–Ментену):

```
dC/dt = input(t) / Vd − Vmax × C / (Km + C),   C ≥ 0,  C(0) = 0
```

Свойства:

* при C ≫ Km выведение почти постоянно: `Vmax × C/(Km+C) ≈ Vmax` — нулевой порядок, около 0,15 ‰/ч;
* при C → 0 скорость падает, кривая асимптотически подходит к нулю и не становится отрицательной;
* пик возникает, когда поступление сравнивается с выведением, а не в момент порции.

## 3. Численная схема

Явный метод Эйлера с шагом 1 минута:

```
каждую минуту:
    добавить порции, время которых наступило (a_i = D_i)
    input = ka × Σ a_i
    C = max(0, C + (input / Vd − Vmax × C / (Km + C)) × Δt)
    a_i = max(0, a_i − ka × a_i × Δt)
```

Ошибка относительно RK4 при таком шаге — меньше 1 %, что много меньше физиологического разброса.
Модель — **чистая функция** от (порции, параметры, время): никакого накопленного состояния,
поэтому добавление/удаление порции или смена веса пересчитывает всю кривую целиком, и прошлое
с прогнозом всегда согласованы.

## 4. Производные величины

* **Текущий уровень** — значение кривой на `now` с линейной интерполяцией между минутами.
* **Пик** — максимум кривой на горизонте: значение и время.
* **Время до порога** — первый момент после пика, когда C(t) ≤ порога. После пика кривая
  монотонно убывает, поэтому решение единственное.
* **Время до нуля** — то же для C ≤ 0,001 ‰.
* **Остаток** — `T_drive − now`, форматируется как «2 ч 14 мин».

## 5. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Нет порций | кривая = 0, статус «Трезв» |
| Добавили порцию | полный пересчёт, в точке `now` излом вверх |
| Удалили порцию | полный пересчёт, меняется и прошлое — это ожидаемо |
| Изменили вес/пол/ka/Vmax | полный пересчёт всей кривой |
| Прошло больше 24 ч | старт интегрирования не раньше `now − 24 ч`, старые порции не влияют |
| Часы/пояс | всё в epoch-миллисекундах UTC, отображение локальное |
| Уровень > 4 ‰ | шкала упирается в максимум, число показывается точно, включается предупреждение |
| Приложение закрыто | состояние восстанавливается из DataStore |

## 7. Почему не «формула Видмарка целиком»

Классическая формула `C = D/(r·m) − β·t` даёт мгновенный скачок в момент порции и линейное
падение до нуля, что противоречит физиологии: уровень растёт постепенно и никогда не уходит
в отрицательные значения. Поэтому всасывание описано кинетикой первого порядка, а выведение —
Михаэлисом–Ментеном; Видмарк остаётся в основе объёма распределения (r) и среднего темпа
выведения (Vmax).
